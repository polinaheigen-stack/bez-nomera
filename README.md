# Без номера — E27

Поиск одного автомобиля на разных фотографиях по внешнему виду, без распознавания номера. Одна обученная DINOv3 ViT-S+/16 создаёт вектор из 384 чисел. Галерейные соседи и k-reciprocal уточняют выдачу; фиксированный порог определяет отказ. Веб и пакетный экспорт используют один алгоритм.

Фиксированный порог: **0,713592811641558**. Он выбран на отдельной калибровке 73 запроса / 612 кадров: максимальный F1 официального оценщика при TNR ≥ 0,95. Контроль 77 / 324 не использовался для перенастройки порога.

## Быстрый запуск: Docker Compose

Нужны Python 3.10+ для импорта, Docker с Compose и свободное место для образа. Для GPU — NVIDIA-драйвер и NVIDIA Container Toolkit; на Windows — Docker Desktop с WSL2. Интернет нужен при первой сборке образа. При распознавании веса и внешние сервисы из сети не загружаются.

### 1. Импортировать модель

Получите исходники и соответствующую папку `Модель_E27` из комплекта сдачи. В ней один checkpoint и метаданные. Из корня исходников:

```text
python scripts/import_model.py --source "путь/к/Модель_E27"
```

Импорт проверяет SHA-256 и совместимость. Веса не входят в Git: `model.pth`, 118 036 485 байт, SHA-256 `300b1c0ba907fa90ceacc38693713789cfb2a8b83248fd585fadb0d059381fdd`.

### 2. Запустить интерфейс

SHA-256 исходников проверяется автоматически при сборке. `SOURCE_MANIFEST_SHA256` вручную задавать не требуется. Используйте исходники и папку модели из одного комплекта; не редактируйте файлы после проверки манифеста.

```text
docker compose build web
docker compose up -d --force-recreate web
```

Откройте http://127.0.0.1:8027 и дождитесь готовности модели. GPU выбран по умолчанию. В интерфейсе: галерея с рамками → индексация → запросы с рамками → поиск → эталонные ответы → качество → скачать результаты. Подробно: [инструкция](docs/USER_GUIDE.md).

Для компьютера без GPU:

```text
docker compose --profile cpu stop web web-cpu
docker compose --profile cpu up -d --build --force-recreate web-cpu
```

Не запускайте оба веб-сервиса на одном порту одновременно. CPU пригоден для функциональной проверки; его время не является GPU-замером. Журнал: `docker compose logs web` (для CPU — `web-cpu`). Остановка: `docker compose --profile cpu down`.

### 3. Получить файлы оценщика

Для пакетного запуска создайте `.env` в корне исходников:

```dotenv
VEHICLE_DATASET_DIR=/absolute/path/to/dataset
VEHICLE_RESULTS_DIR=/absolute/path/to/results
```

Первый каталог содержит `images/` и CSV; второй доступен на запись. Используйте свои абсолютные пути. Затем:

На Linux каталог результатов должен быть доступен UID контейнера `10001`.

```text
docker compose run --rm export --images /data/images --query /data/test_query.csv --gallery /data/test_gallery.csv --output /results/my-run
```

При наличии соответствующего эталона добавьте `--ground-truth /data/ground_truth.csv`. Для CPU замените начало на `docker compose --profile cpu run --rm export-cpu`. Выход `my-run` должен быть новым. Получатся `submission.csv`, `candidates.csv`, `embeddings.npy` и метаданные. [Форматы и проверка](docs/BATCH.md).

## Подтверждённые результаты

На историческом контроле 77 запросов / 324 кадра: **mAP@10 82,139%; Rank-1 82,258%; Rank-5 93,548%; F1 90,265%; TNR 100% (15/15)**. Метрики рассчитаны официальным оценщиком при новой постобработке сохранённых GPU-признаков стенда 5. Это не новый независимый или скрытый тест и не повторный GPU-прогон всей E27.

Ускоренное извлечение признаков на NVIDIA A10: **119,547 фото/с**, против 46,158 фото/с базового режима в том же прогоне (**2,59×**). Параметры: FP32, 4 обработчика, пакет 32, pinned memory. Для одного снимка: медиана **34,903 мс**, p95 **39,302 мс**; 50 прогревов и 300 синхронизированных измерений. Замер включает чтение, decode, рамку, подготовку, передачу на GPU, сеть, нормализацию и возврат вектора. Кэш готовых изображений/тензоров не используется; файловый кэш ОС прогрет. **Галерейный поиск, реранкер и HTTP в этот замер не входят; полная задержка E27 не измерялась.**

Свежие GPU-векторы ускорителя прошли проверки калибровки и контроля в пакетном и одиночном режимах: top-10, принятия, отказы и официальные метрики сохранены; максимальное отклонение компонента — 2,69×10⁻⁶ при допуске 10⁻⁵. Порог не перенастраивался. Это регрессионная проверка, а не новый независимый контроль.
