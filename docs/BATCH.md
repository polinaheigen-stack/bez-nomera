# Пакетный запуск

Используется тот же пакет модели E27, что в браузере. Сначала выполните импорт модели и сборку из [README](../README.md). Не нужно искать файлы старых стендов.

## Вход

Каталог датасета: `images/`, query CSV и gallery CSV. Обе таблицы содержат `image_id,x,y,w,h`. Файлы JPEG/PNG; ID без расширения совпадает с именем. Координаты относятся к исходному кадру. Изменять размеры фотографий заранее не требуется. Минимальная галерея — 10 кадров.

В `.env` задайте `VEHICLE_DATASET_DIR` и `VEHICLE_RESULTS_DIR` своими абсолютными путями. Compose монтирует их соответственно в `/data` (чтение) и `/results` (запись).

```text
docker compose run --rm export --images /data/images --query /data/test_query.csv --gallery /data/test_gallery.csv --output /results/my-run
```

Папка `my-run` должна быть новой. Для компьютера без GPU используйте `docker compose --profile cpu run --rm export-cpu` с теми же аргументами.

Контроль 77/324 при наличии полного исходного датасета: CSV и эталон уже включены в образ. Отдельно собирать фотографии в папки не требуется:

```text
docker compose run --rm export --images /data/images --query /app/control/query.csv --gallery /app/control/gallery.csv --output /results/control77 --ground-truth /app/control/ground_truth.csv
```

Команда выполняет новый поиск по исходным фотографиям. Сохранённые признаки из исследовательских отчётов здесь не подставляются.

## Качество

Если есть эталон именно данного набора, добавьте:

```text
--ground-truth /data/ground_truth.csv
```

Эталон содержит `image_id,vehicle_id,camera_id,split`. Он передаётся официальному оценщику после поиска. Метки не поступают в модель. Эталон контроля 77/324 нельзя применять к другим фотографиям из другого набора.

Без эталона экспорт корректен, но mAP, Rank, F1 и TNR неизвестны. Число принятий и процент сходства их не заменяют.

## Результат

`submission.csv`, `candidates.csv`, `embeddings.npy` и JSON с порядком изображений, рецептом и происхождением. При эталоне — отчёт качества. Сохраните весь каталог одного запуска, а не CSV из разных запусков. Размерность исходных признаков E27 — 384; query-строки идут перед gallery-строками.

Назначение трёх файлов подробно описано в [архитектуре](ARCHITECTURE.md). Команды Docker требуют доступного импортированного checkpoint; при ошибке модель не заменяется заглушкой.
