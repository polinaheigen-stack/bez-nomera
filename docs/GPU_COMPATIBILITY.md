# GPU и CPU

Основной способ запуска — Docker Compose из README. GPU выбран по умолчанию, CPU включается явно отдельным сервисом.

GPU: Linux или Windows/WSL2, Docker Compose, совместимый NVIDIA-драйвер и NVIDIA Container Toolkit. Выбранный ускоритель FP32 проверен на NVIDIA A10 24 ГБ, PyTorch 2.8.0+cu126, CUDA 12.6. Это подтверждённая конфигурация ускоренного encoder, не минимальный объём памяти и не замер всей E27. RTX A5000 организаторов отдельно не проверялась.

CPU: `docker compose --profile cpu up -d --build --force-recreate web-cpu`. Сначала остановите GPU-сервис: `docker compose --profile cpu stop web web-cpu`. Порт по умолчанию 8027. Время CPU нельзя сравнивать с GPU-нормативом.

При отсутствии CUDA сервис GPU сообщает ошибку; скрытой подмены GPU на CPU нет. Устройство видно в настройках и результатах. Смена устройства требует переиндексации галереи. Запуск на CPU не меняет рецепт, порог и число признаков.

При ошибке проверьте `docker compose logs web`, наличие импортированных весов и доступ Docker к GPU. Сборка образа использует сеть для зависимостей; распознавание после сборки не загружает ничего из сети.
