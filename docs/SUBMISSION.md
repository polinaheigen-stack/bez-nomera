# Комплект сдачи E27

## Репозиторий

Исходники приложения и интерфейса, `docker-compose.yml`, Dockerfile, README, lock-файлы зависимостей, скрипты импорта и экспорта, документация, исходники обучения выбранной модели и лицензии. Checkpoint и teacher cache хранятся отдельно от Git.

## Отдельные материалы

- `Модель_E27/`: один checkpoint с метаданными и лицензией DINOv3.
- `Презентация.pptx` и `Презентация.pdf`: редактируемые слайды и копия для просмотра.
- `Инструкция.pdf`: загрузка галереи, запросов, эталона и получение результатов.
- `Видео.mp4`: инструкция по интерфейсу; иллюстрации сохранённых результатов явно подписаны.
- Материалы доказательств: GPU-замер ускорителя, регрессионная проверка новых GPU-векторов и официальная оценка постобработки, версии и контрольные суммы.
- `Обучение_E27/`: teacher cache и служебные CSV для повторения обучения; для запуска готового решения не нужны.
