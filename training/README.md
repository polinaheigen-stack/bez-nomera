# Обучение выбранной модели E27

E27 использует неизменённые веса ранее обученного стенда 5. Запуск готового решения не требует обучения, teacher cache или начальных весов из интернета. Единственная производственная модель — DINOv3 ViT-S+/16, вход 256×256, признаки 384D. Checkpoint эпохи 14 выбран после завершённых 20 эпох по максимуму mAP@10 на отдельной выборке разработки.

## Фактические настройки

- Данные обучения: 6804 фотографии, 1098 автомобилей. Разработка: 1134 фотографии, 220 автомобилей; query 220 / gallery 914. Калибровка: 73/612. Контроль: 77/324. Эти части проверяются на разделение.
- Batch: P=8 машин × K=4 снимка = 32. Seed 20260929; 20 эпох по 213 выбранных sampler-пакетов. Это не утверждение, что каждый снимок встречается ровно один раз за эпоху.
- AdamW: backbone learning rate 2e-5, проекция и классификатор 1e-3, weight decay 0.01; прогрев 2 эпохи, cosine decay.
- Потери: Cross-Entropy со сглаживанием 0.1, soft-margin batch-hard triplet и KL-дистилляция отношений между тренировочными изображениями. Вес дистилляции 1, температура 0.1.
- Учитель — собственный E25. Использованы только его 6804 чистых тренировочных вектора 1024D. При поиске учитель отсутствует.
- Аугментации: отражение с вероятностью 0.5, яркость/контраст/насыщенность 0.9–1.1. Дистилляция получает чистый crop. Random erasing и jitter рамок выключены.
- При обучении CUDA BF16, если поддерживается; готовый encoder вычисляется в FP32 без autocast и TF32. Веса classifier нужны только при обучении.

Полный профиль — `profiles/stand-5.json`. Выбор эпохи и 20 журналов находятся в `records/`. `student-calibration.json` в records — исходная историческая калибровка тренировочного испытания, **не текущий порог E27**. Рабочие настройки новой постобработки находятся в производственном пакете модели; порог E27 — 0.713592811641558.

## Повторить обучение

Нужны CUDA-GPU, исходный датасет организаторов, Python 3.11/3.12 и отдельное окружение. Из корня репозитория:

```text
python -m venv .venv-training
```

Активируйте созданное окружение своей ОС. Установите CUDA-вариант PyTorch 2.8.0 и torchvision 0.23.0 согласно оборудованию, затем закреплённые зависимости:

```text
python -m pip install -r training/requirements.lock
python training/fetch_pretrained.py
```

Последняя команда единожды скачивает закреплённые исходные веса DINOv3 с проверкой размера и SHA-256. Лицензия лежит рядом. Это подготовка обучения; производственный инференс ничего не скачивает.

Из отдельного пакета `Обучение_E27` скопируйте `teacher-train-cache/` в `training/assets/teacher-train-cache/`. Служебные CSV уже есть в `training/inputs/`; исходные фотографии предоставляет организатор. Укажите каталог датасета с `images/` и исходными CSV. Для проверки входов без обучения:

```text
python training/run_training.py --dataset "путь/к/датасету" --output "новая/папка/preflight" --preflight-only
```

Для обучения используйте другой, ещё не существующий каталог:

```text
python training/run_training.py --dataset "путь/к/датасету" --output "новая/папка/training-run"
```

Эта команда воспроизводит исходное испытание стенда 5: проверка данных → обучение → выбор по dev → историческая калибровка → контроль → проверка повторяемости → замер encoder. Она не заменяет текущую постобработку E27 и не перезаписывает поставленные веса. Другая аппаратура может дать численные отличия; побайтовое совпадение нового обучения не обещается.

## Происхождение

В `runtime/` сохранены необходимые исходные модули исходного обучения с их хешами. Общие helper-модули содержат исторические имена, потому что использовались исходным тренировочным кодом; самостоятельные наборы других экспериментов, профили и веса не включены. Входной wrapper разрешает только stand-5. Манифест `COPIED_TRAINING_SOURCE_SHA256.json` проверяет точные копии до запуска.

Выбранные веса: SHA-256 `300b1c0ba907fa90ceacc38693713789cfb2a8b83248fd585fadb0d059381fdd`, 118 036 485 байт. Начальные веса: `timm/vit_small_plus_patch16_dinov3.lvd1689m`, revision `c35074f0e1a65242948168c9358ce26705c4deb2`, SHA-256 `423e7b4b1103de4100a5c19a436cc00f1a994d82835ed51623b209ccfd1e9615`.

Teacher cache: 6804×1024, SHA-256 массива `b51271cd8b43f478d590f888a34785cbe9401f62012d926668487bc81fd04498`; receipt и метаданные поставлены вместе с ним. Cache получен на оригинальных тренировочных crop, без реранкера и без тестовых запросов. Обучение не использует порог E27 или ответы контрольного набора для выбора эпохи.

Условия DINOv3 сохранены полностью в `assets/dinov3-splus/LICENSE.md`; передавайте их вместе с производными весами. Исходный датасет не объявляется открыто лицензированным.
